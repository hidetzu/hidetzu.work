# ADR 0005: 数学ノートの章立て・証明の出どころ・依存関係

- 日付: 2026-11-14
- 状態: 採用（1 節の教科書の章立ては、ADR 0008 で「参考文献と学習記録」に改めた）
- 関連: [ADR 0002](0002-add-math-notes.md)、[ADR 0003](0003-organize-math-notes-by-field.md)

## 背景

ノートが 13 本になり、Munkres の Chapter 1 §1〜§4 と Chapter 2 §12・§13 にまたがった。次の点が読み返しにくくなっていた。

- 教科書のどの節を学んだかが、一覧から分からない（分野の一覧しかない）
- 証明の出どころ（自力・教科書・Claude の補足）が、ノートごとの文章にしか書かれていない。ページ全体の `status` と混ざりやすい
- 定理を証明するために何を使ったか、どの結果が後で使われるかを、ページの中でもページの間でも追いにくい
- 定理・証明のブロックがカード状で、長い証明が続くと主張と証明の区切りが重い。
  見出しに「定理（定理 4.1（整列性））」のような二重の表記が出ていた

## 決定

### 1. 教科書の章立てと分野の 2 つの見方を併置する

- ノートの frontmatter に `textbook: { chapter, section? }` を足し、`/math` に「教科書の章立て」の一覧を置く。
  章・節の題は `src/data/math.json` の `chapters` に、確かめたものだけを書く
- 節を記録していないノートは「節を記録していないノート」として章の下に、教科書と対応しないノートは別にまとめる。
  節を推測で埋めない
- 分野（`topic`）の一覧はそのまま残す。概念の細かい分類（写像・関係・順序など）は分野を増やさず、
  分野の中のノートで表す。URL は変えない

### 2. 証明の出どころを証明ごとの属性で記録する

- `:::proof{origin=… text=… note=…}`。値は `self` / `self-reviewed` / `textbook` / `ai` と、文章を Claude が整えた印 `text=ai`
- 既存のノートには、各ノートの「学習状況」と「このノートの書き方」に書かれた記録から付けた。記録から判断できない証明には付けていない（「記録なし」）
- ページ全体の `status` は自己申告のまま変えない。`/math` の凡例で 2 つを分けて説明する

### 3. 依存関係は証明の中のリンクから集める

- 証明の中のリンクを「使った結果」とし、ノート末尾に定理ごとの依存関係、`/math` にノート間の依存関係を出す
- 依存関係のための別のメタデータ（frontmatter の一覧など）は作らない。本文のリンクと二重に管理しないため
- 図（グラフ）は作らない。今の規模では一覧とリンクで足りる
- 引用して置いた主張（例: 有理数の稠密性のノートのアルキメデスの性質）は `ref` で証明のあるノートにつなぐ

### 4. 組版を数学書に寄せる

- カードと背景色をやめ、主張は左の細い罫、証明は罫なしで主張の下に続け、最後の行の右端に ∎
- ラベルの先頭の番号を種類名の側に出す（「補題 3.1（…）」）
- 日本語の文の途中の改行が空白として表示されないようにする
- 目次に 2 段目の見出しも入れる。証明の折りたたみは入れない（長い証明でも常に読めるようにする）

## 採用しなかった案

- **依存関係図をクライアント JS で描く** — README の方針（クライアント JS 0）に反し、今の規模では一覧で足りる
- **分野を細かく分ける（写像・関係・順序を独立した分野にする）** — 既存ノートの分野の付け替えが必要で、Chapter 1 の節と二重になる
- **証明の出どころを frontmatter の一覧で持つ** — 証明と離れた場所に書くと、証明を足したときに更新を忘れる
