# ADR 0008: Math Notes を特定の教科書に依存しない数学ノートとして位置づける

- Status: Accepted
- Date: 2026-11-17
- 関連: [ADR 0002](0002-add-math-notes.md)、[ADR 0003](0003-organize-math-notes-by-field.md)、[ADR 0005](0005-math-notes-structure-and-proof-records.md)

## 背景

Math Notes は Munkres の *Topology* を学ぶ過程で書き始めたため、`/math` の冒頭や各ノートの導入文が
「Munkres の §○ で学んだ内容を整理したもの」という書き方になっていた。`/math` でも「教科書の章立てで見る」が分野より先にあった。
今後はほかの書籍や資料も参照する予定で、Munkres を唯一の基準にした構成では、複数の資料から学んだ内容を統合しにくい。

また「（補足）」が、ノートによって「教科書の範囲外」「Claude が足した説明」「証明に補った確認」と別の意味で使われていた。

## 決定

### 1. 位置づけ

Math Notes は、書籍や資料から学んだ定義・定理・証明を、自分の理解で組み立て直し、具体例・反例・自分の証明を加えて育てていく個人の数学ノートとする。
Munkres は重要な参考文献の一つで、ノート全体の構造を決める唯一の基準にはしない。

- ノートの description と導入文は、そのページで扱う数学的概念を中心に書く
- Munkres の定理・演習を直接扱う箇所では、番号と対応をはっきり残す（学習記録として必要なため）

### 2. `/math` の構成

- 主な導線は分野（`fields`）。ページの先頭に置く
- 参考文献ごとの章立ては「参考文献と学習記録」として、補助的な位置に置く。旧アンカー `#textbook` は残す
- ノートの Study log（旧 Textbook）は、参考文献の短い名前と章・節を出す

### 3. 参考文献のデータ

- `src/data/math.json` の `textbook` と `chapters` を、`references`（`id`、`title`、`short`、任意の `chapters`）の配列にした。実際に参照した資料だけを足す
- frontmatter の `textbook` に任意の `ref`（`references` の id）を足した。省略すると先頭の資料（Munkres）
- frontmatter の `sources` に任意の `note` を足した。資料との対応の補足（範囲外の節など）を書く

### 4. 「（補足）」の意味

「（補足）」は、読者の理解を助けるための追加の説明（直観的な説明、具体例、反例、別の証明、他分野との関連）の印とする。

- 参考文献の範囲内か範囲外かは、`sources` の `note` で管理する
- 証明を誰が書いたかは、これまでどおり `origin` / `text` で表す
- 既存のノートで「Claude が補った確認」を（補足）で示している箇所は、出どころの記録を兼ねているので、そのまま残す

## 採用しなかった案

- **frontmatter の `textbook` を別の名前に変える** — 全ノートの書き換えになり、得るものが少ない。意味（学習記録）はコメントと README で示す
- **既存の（補足）の印を一括で外す・書き換える** — 証明の中の印は出どころの記録を兼ねている。意味を変えずに残す

## 残る課題

原著の表現・例・証明の構成に近い可能性がある箇所は、本と照合して確認する必要がある。
参考文献を記載したことや翻訳ではないと書いたことだけでは、独立した説明になっているとは言えない。
