# ADR 0004: 数学の記号・文字リファレンスを追加する

- 日付: 2026-11-14
- 状態: 採用
- 関連: [ADR 0002](0002-add-math-notes.md)、[ADR 0003](0003-organize-math-notes-by-field.md)

## 背景

Munkres を英語で読んでいると、見慣れない文字・書体・記号や、数学特有の英語表現に出会う。
そのたびに名前・読み方・意味・LaTeX の書き方をすぐ引ける場所がほしい。
これは学習の記録ではなく辞書なので、学習ノート（Content Collections）とは性格が違う。

## 決定

- `/math/notation` に 1 ページのリファレンスを置く。文字・記号・読み方・用語集・参考資料を 1 ページにまとめ、
  ページ内検索で探せるようにする。ページは分けない
- 学習ノートではないので、Content Collections と分野（`topic`）には入れない。`/math` からは
  教科書の行の下にリンクを置く
- 中身は `src/data/math-notation.ts` の型付きのデータにし、ページ（`src/pages/math/notation.astro`）は表を組むだけにする。
  項目を足すときはデータだけを触る
- 数式は Markdown を通さないので、`src/lib/tex.ts` で KaTeX を直接呼ぶ。オプションはノートと同じで、
  TeX の誤りはビルドで落とす
- クライアント JS は 0 のまま（README「実装の方針」）。検索ボックスとコピーボタンは作らず、
  ブラウザのページ内検索と、LaTeX のコードを 1 回のクリックで全選択できる CSS（`user-select: all`）で代える
- スマートフォンでは表の 1 行を 1 枚のカードにして、各欄に見出しを付ける

## 内容の約束

- 意味の欄は一般的な使い方を書く。本によって違う記号（`\subset` が等号を許すかなど）は注に書き、一つに決めつけない
- Munkres 固有の書き方は、確かめられたものだけを書き、確かめた資料を参考資料に挙げる。推測で書かない
- まだ学んでいない分野（順序関係、閉包・連続写像など）は、記号と一般的な意味だけにする
- 説明と例文はこのページのために書く。資料の文章を転載しない

## 採らなかった案

- **記号ごとに 1 ページ、またはカテゴリごとにページを分ける**: 探すときにページをまたぐことになり、
  ページ内検索が効かない
- **Markdown のノートとして書く**: 6 列の表を Markdown で保守するのはつらく、スマートフォン向けの
  カード表示や、LaTeX の欄の書式をそろえにくい
- **JS の検索ボックス**: 項目数が数百程度なら、ブラウザのページ内検索で足りる。サイトのクライアント JS 0 の方針を崩すほどの利点がない
