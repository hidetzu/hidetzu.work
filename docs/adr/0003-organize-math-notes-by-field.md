# ADR 0003: 数学ノートを分野ごとに整理する

- 日付: 2026-11-09
- 状態: 採用
- 関連: [ADR 0002](0002-add-math-notes.md)

## 背景

数学ノートは、位相空間論（§12, §13）、実数（有理数の稠密性）、論理学と増えてきた。
これから Munkres の Chapter 1（集合論）から位相空間論へ進むので、ページと概念はさらに増える。
`/math` の一覧は更新日順の 1 本のリストで、分野の区別も、概念どうしのつながりもなかった。

## 決定

### 1. 分野はメタデータで表し、URL の階層にしない

- 分野（論理学・集合論・組み合わせ論・実数・位相空間論）は `src/data/math.json` の `fields` に定義し、
  ノートは frontmatter の `topic` に分野の id を書く。定義にない id はビルドエラーにする
- URL は `/math/<slug>` のフラットなまま。分野を URL に入れると、ノートの分野を変えたときに URL が変わり、
  リダイレクトが必要になる。既存の URL はすべてそのまま残る
- `/math` は分野ごとにノートをまとめた目次にする。分野の中は `order`（なければ作成日）の順。
  ノートのない分野は表示しない（空のページや空の見出しを先に作らない）
- 分野ごとのページ（`/math/logic` など）は作らない。`/math#logic` で足りる

### 2. 概念ごとにノートを分ける

1 ノートは 1 つの概念か、密接な概念のまとまりにする。論理学のノートは
「命題論理の基礎」と「含意と対偶」に分け、集合の内容は集合論のノートに移した。
論理と集合の対応（ド・モルガンの法則など）は、片方で長く説明して、もう片方からリンクする。

### 3. 関連するノートは frontmatter の related で双方向に出す

- `related` に関連するノートの slug を書くと、ノートの末尾に「Related」として出す
- 相手のノートにも逆向きのリンクを自動で出すので、片方に書けばよい
- 存在しない slug はビルドエラーにする
- 本文中の個別の参照（定理や例への `#id` リンク）は、これまでどおり本文に書く

## 採用しなかった案

- **`/math/<分野>/<slug>` の階層 URL** — 既存 URL の変更とリダイレクトが必要になり、分野の付け替えにも弱い
- **分野ごとのインデックスページ** — ノートが少ないうちは `/math` の見出しで足りる
- **知識グラフや概念間の依存関係の可視化** — ADR 0002 と同じ理由で過剰。related のリンクで足りる
- **学習状況を細かく分ける（定義を確認済み・自力で証明済み・レビュー済みなど）** — 実際の学習記録がないまま付けることになる。
  ノート単位の `status` と、本文の「（補足）」の区別を続ける（ADR 0002）
