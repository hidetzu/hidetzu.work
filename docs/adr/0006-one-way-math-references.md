# ADR 0006: 数学ノートの参照は一方向にする

- Status: Accepted
- Date: 2026-11-14

## 背景

集合論の基礎ページに「§13 の証明で使った」「§12 の有限補集合位相で使う」のような、後続の節での使用を記した文が残っていた。
また、ノート末尾の「証明の依存関係」は、定理ごとに「この結果を使う証明」を、Dependencies は「このノートの結果を使うノート」を自動で並べていた。
前提の側のノートに後続の使用例が増えていくと、基礎のノートが学習履歴の羅列になり、読みにくくなる。

## 決定

- 数学的な参照は「後続の定理・証明 → 必要となる前提の定義・定理」の一方向にする
- 前提の側のノートの本文には、その結果を使う後続の証明や節を書かない
- ノートのページには、証明で使う結果（`uses`）と、証明で使うノートだけを出す。逆向き（`usedBy`、`noteUsedBy`）は表示しない
  - 集計（`src/lib/math-graph.mjs`）は逆向きも作る。テストと将来の確認用で、ページには出さない
- `/math` のノート間の依存関係は、もともと「証明で使う」の向きなので変えない
- frontmatter の `related`（関連知識）は依存関係とは別のもので、これまでどおり両方向に出す

## 同時に決めたこと

- `sets`（集合と包含関係）と `set-operations`（集合演算とド・モルガンの法則）を `sets`「集合の基本と演算」に統合した。
  アンカーはすべて引き継ぎ、`/math/set-operations` は `public/_redirects` で `/math/sets` へ 301 リダイレクトする
  （Cloudflare Workers Static Assets が `_redirects` を読む。リダイレクト後もフラグメントはブラウザが引き継ぐ）
- 同じ方針で、`propositional-logic`（命題論理の基礎）と `implication`（含意と対偶）を `propositional-logic`「論理の基礎」に統合した。
  URL の互換性を優先してスラッグは変えず、`/math/implication` は `/math/propositional-logic` へ 301 リダイレクトする

## 見送ったこと

- 冪集合・集合族・直積などのノート本文に残る、後続の節への言及の削除。今回の対象外で、必要になったときにノートごとに整理する
