# ADR 0007: 機械学習の学習マップ（/ml）を追加する

- Status: Accepted
- Date: 2026-11-15

## 背景

機械学習の理論と歴史を、プログラマーの視点から体系的に学び、記録したい。
目標は、証明を厳密に完成させることよりも、技術の登場背景・解決した問題・仕組み・限界・その後の発展を自分の言葉で説明できることにある。
/math（Munkres の位相空間論を厳密に学ぶノート）とは目的も記録の単位も違う。

## 決定

- `/ml` を、/math とは独立したセクションとして追加する。ヘッダーのナビゲーションに「ML」を足す
- v0.1 は全体マップだけにする。個別の技術の詳細記事は、本人が学んでから書く
- 学習マップのデータは `src/data/ml.json` に置く
  - 8 つの領域（`areas`）：問い、主な分類軸、学ぶ項目、前提の領域、理解の状態
  - 領域のつながり（`edges`）：実線は前提で、`prerequisites` と一致しないとビルドで落とす。破線は内容の関連
  - 学ぶ順序（`order`）と、歴史的転換点の年表（`timeline`）
- 理解の状態は「未評価・学習中・概念理解・自分の言葉で説明可能」の 4 段階で、領域ごと（`ml.json`）とノートごと（frontmatter）に自己申告で記録する。初期値はすべて未評価
- 学習ノートは Content Collections の `ml`（`src/content/ml/<slug>.md` → `/ml/<slug>`）に置く。雛形は `docs/ml-note-template.md`。
  まだノートがないので、ビルド時に「collection が空」という警告が出る
- 学習マップの図は、ビルド時に組み立てるインライン SVG にする。Mermaid などのクライアント JS は使わない
- 見た目は math.css を共有し、/ml に固有のものだけ `src/styles/ml.css` に書く。Markdown の処理（KaTeX、ブロック）も /math と共有する。
  KaTeX のフォントを読み込むページに /ml を加える
- 年表の年は、原論文などの一次資料（DOI、arXiv、プロシーディングス）で確かめたものだけを書き、出典へリンクする。
  プレプリントと会議の年が違うものは、会議の年を使ってプレプリントの年を併記する
- 歴史的事実（年表）・確立した理論や手法・研究中のテーマを区別して表示する
- 領域の説明と年表は Claude がまとめた見取り図であることをページに明記する。本人の理解は、各ノートの「自分の理解」にだけ書く

## 見送ったこと

- 学習の進捗の記録システム（チェックリストや履歴）。状態は JSON と frontmatter の 1 項目で足りる
- 個別の技術ノートの先行作成。未作成のページへのリンクは出さない
